PZEM ölçümleri kendi içinde hesaplar; bu klasör register verilerinin yorumlanması ve bağımsız tutarlılık kontrolü içindir. PZEM-014: 0–10 A, dahili şönt. PZEM-016: 0–100 A, harici CT. Bu modelleri aynı ölçekle veya bağlantıyla ele alma.
