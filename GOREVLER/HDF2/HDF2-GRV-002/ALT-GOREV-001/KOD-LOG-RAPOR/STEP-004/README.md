# STEP-004 — SCT ve BIAS dalga grafikleri

**Durum:** BEKLİYOR

- Doğrulanmış ham kayıttan SCT ve BIAS örneklerini çiz.
- İlk incelemede hesaplama/filtreleme yapma; ham sinyal gösterimini koru.
- İlk beş frame'in grafiklerini ve kullanılan veri dosyasını kaydet.
- X ekseninin örnek indeksi mi, doğrulanmış zaman mı olduğunu açıkça belirt.

Başarı kanıtı: kaynak CSV/binary kayıt ve üretilen grafik dosyaları.
