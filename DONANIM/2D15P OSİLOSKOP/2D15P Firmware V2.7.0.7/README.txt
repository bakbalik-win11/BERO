----------------------------------------

⚠ IMPORTANT NOTES
- Do not disconnect the USB connection during the file transfer.
- Use firmware only for the correct model
- Interrupting upgrade may damage the device

----------------------------------------

[ UPGRADE STEPS ]
1. Connect the device to a computer (Windows system) using a USB Type-C cable.
2. Turn on the device's USB Sharing function.
3. The computer will automatically recognize the device as a USB drive.
4. Drag and drop the firmware file into the "Upgrade file" folder; do not operate the device or disconnect the USB connection during the file transfer.
5. Once the file transfer is complete, disconnect the USB cable, turn the device off and then on again; the device will automatically begin the upgrade process.
6. The device will automatically restart after the upgrade is complete.
