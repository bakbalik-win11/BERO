# Şebeke güvenlik kontrol listesi

**220–240 V AC ölümcül olabilir.** Bu liste uzman incelemesinin yerine geçmez. Şebeke bağlantısını yalnızca yetkin kişi, uygun muhafaza ve koruma ile kurmalıdır.

**Kayıt durumu:** Kullanıcı 2026-10-27 tarihinde T002 listesini okuyup tüm kontrolleri tamamladığını beyan etti. Aşağıdaki maddeler bu beyana dayanarak işaretlenmiştir; asistan tarafından fiziksel olarak gözlemlenmiş veya bağımsız olarak test edilmiş değildir.

- [x] Kablolama öncesi besleme kesildi ve enerjisiz olduğu uygun cihazla doğrulandı.
- [x] Şebeke terminalleri kapalı muhafaza içinde.
- [x] Sigorta/koruma, kablo kesiti, klemens ve izolasyon aralıkları doğrulandı.
- [x] Şebeke ve düşük gerilim/USB/MCU taraflarının izolasyonu kontrol edildi.
- [x] CT yalnız tek yalıtılmış iletken etrafında.
- [x] CT sekonderi üretici talimatına aykırı şekilde açık bırakılmıyor.
- [x] PZEM varyantı ve CT bağlantısı kılavuza göre doğrulandı.
- [x] ADC'ye izin verilen aralık dışında gerilim gitmiyor.
- [x] Analog bias ve VREF fiziksel ölçüldü.
- [x] Kablolama ikinci yetkin kişi tarafından incelendi.
- [x] İlk enerjilendirme kontrollü koşullarda, muhafaza kapalıyken yapıldı.

**Durum: KULLANICI BEYANINA GÖRE TAMAMLANDI (2026-10-27).** Bu kayıt, fiziksel güvenliğin bağımsız doğrulaması değildir. Kurulumda değişiklik olursa ilgili maddeler yeniden kontrol edilmelidir.
