# ADR-004: Sürekli ham ADC arşivi tutulmayacak

- **Durum:** Kabul edildi.
- **Karar:** Normal kayıtta pencere istatistikleri; olay algılandığında RAM halkalı tamponundan kısa öncesi/sonrası ham kesit.
- **Gerekçe:** Sürekli osiloskop arşivi yerine yönetilebilir veri hacmi.
- **Risk:** Özetlerde bulunmayan dalga biçimi bilgisi sonradan geri alınamaz.
- **Gözden geçirme:** E06'da özetlerin olayları ayırmaya yetmediği gösterilirse.
