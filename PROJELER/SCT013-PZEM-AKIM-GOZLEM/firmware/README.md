# Eski firmware envanteri — tarihsel arşiv

Bu klasördeki YAML ve firmware dosyaları önceki SCT/PZEM akım okuma hedefi, eski Modül 2/3, ESP32D1/WROOM/D2, SSR/UDP olay denemeleri ve ADS1115 deneyleri için saklanmıştır.

**Durum:** Tarihsel arşiv. Buradaki hiçbir dosya PREBERO'nun aktif firmware'i veya yeni Modül 4 için onaylanmış kod değildir. YAML'ın depoda bulunması güncel kartta derlendiğini veya çalıştığını kanıtlamaz.
