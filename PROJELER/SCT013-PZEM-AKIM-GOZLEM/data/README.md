# Veri yönetimi

- raw/: yerel ham kayıtlar; varsayılan olarak Git'e eklenmez.
- processed/: tekrar üretilebilir küçük çıktılar; kaynak veriyi ve dönüşüm adımını belirt.
- samples/: şema testi için küçük sentetik örnekler.
- Kişisel bilgi, erişim anahtarı veya hassas ağ verisi ekleme.
- Deney yoksa sonuç uydurma.
