# EXP-002 — Osiloskopla analog giriş gözlemi

**Durum:** PLANLANDI.  
**Ön koşul:** T001–T003.

AIN0-GND, AIN1-GND ve AIN0-AIN1 dalga biçimleri bias'lı/bias'sız koşullarda gözlenir. DC çalışma noktası, tepe değerleri ve clipping/gürültü not edilir. Ekran görüntüsü ve prob/time/div/volt/div ayarları saklanır.

Yalnız uygun şekilde izole edilmiş düşük gerilimli SCT/ADS tarafında çalışılır; şebeke iletkenine doğrudan prob bağlanmaz. Henüz ölçüm yapılmadı.
