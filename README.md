# BERO

BERO deposunun ana çalışma alanları:

- [DONANIM](DONANIM/): BERO ve PREBERO tarafından ortak kullanılan donanım kayıtları.
- [ENVANTER](ENVANTER/): Fiziksel bileşen ve malzeme envanteri.
- [PREBERO](PREBERO/): BERO öncesi hazırlık, modül çalışmaları ve görev takibi.

Donanım ve envanter kayıtları merkezi tutulur; PREBERO modülleri bu kayıtları tekrar etmez.
